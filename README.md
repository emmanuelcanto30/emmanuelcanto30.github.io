# Sitio para GitHub Pages

1. Crea un repositorio público llamado `TU_USUARIO.github.io`.
2. Sube `index.html`, `privacy.html` y `app-ads.txt` a la raíz.
3. Ve a **Settings → Pages**.
4. Selecciona **Deploy from a branch**, rama **main**, carpeta **/root**.
5. Tu sitio quedará en `https://TU_USUARIO.github.io`.
6. Verifica `https://TU_USUARIO.github.io/app-ads.txt`.
7. Coloca ese dominio como sitio web del desarrollador en Google Play.
