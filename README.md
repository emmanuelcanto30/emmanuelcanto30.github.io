# Emmanuel Canto Apps — GitHub Pages

Sitio bilingüe español/inglés para:

- Quick Polygon Generator GIS
- Quick Mapper Generator
- Equipment Valuator

## Publicación

1. Descomprime el ZIP.
2. Sube todos los archivos directamente a la raíz del repositorio `emmanuelcanto30.github.io`.
3. Acepta reemplazar los archivos anteriores.
4. Haz clic en **Commit changes**.
5. Espera unos minutos y abre:
   - https://emmanuelcanto30.github.io/
   - https://emmanuelcanto30.github.io/app-ads.txt
   - https://emmanuelcanto30.github.io/privacy.html
