Política de privacidad de Equipment Valuator

Esta política explica cómo la aplicación Equipment Valuator, desarrollada por Jonnathan Emmanuel Uicab Canto, procesa la información cuando el usuario utiliza sus funciones.

1. Información proporcionada por el usuario

La aplicación puede procesar datos técnicos y económicos ingresados por el usuario, tales como marca, modelo, año, costos, edades, vidas útiles, condiciones, comparables y variables utilizadas en los métodos de valuación.

2. Finalidad del procesamiento

La información se utiliza para realizar cálculos, análisis, regresiones, estimaciones de valor y generación de reportes relacionados con vehículos, maquinaria y equipo.

3. Procesamiento y almacenamiento

El procesamiento principal se realiza localmente. Los datos pueden conservarse temporalmente dentro de la aplicación y los archivos CSV o PDF se guardan solo cuando el usuario los importa o exporta.

4. Datos que no se solicitan

  • No se requiere una cuenta para utilizar las funciones principales.
  • La aplicación no realiza pagos ni solicita datos bancarios.
  • El desarrollador no recibe automáticamente los avalúos, comparables ni reportes generados.

5. Importación y exportación

La aplicación puede utilizar el selector de archivos de Android para importar tablas CSV y guardar reportes. El usuario decide qué archivos abre y dónde conserva los resultados.

6. Publicidad y servicios de terceros

La versión distribuida puede mostrar publicidad mediante Google AdMob. Cuando está habilitada, Google y sus socios pueden procesar identificadores del dispositivo, información técnica, interacciones con anuncios y otros datos necesarios para prestar y medir el servicio publicitario.

7. Responsabilidad profesional

La aplicación es una herramienta de apoyo y no sustituye el criterio profesional, la inspección física, la normativa aplicable ni la firma de un valuador autorizado. El usuario es responsable de revisar los datos, supuestos y resultados.

8. Conservación y eliminación

El usuario puede borrar los archivos exportados desde el administrador del dispositivo. La desinstalación elimina los datos internos de la aplicación, salvo documentos guardados en carpetas públicas.

9. Seguridad

Se aplican medidas razonables para limitar el acceso a la información necesaria. No puede garantizarse seguridad absoluta en sistemas electrónicos.

10. Menores y modificaciones

La aplicación está orientada a profesionales y estudiantes de valuación y no está diseñada específicamente para menores. La política puede actualizarse cuando cambien las funciones o los servicios integrados.

Contacto

Para preguntas relacionadas con esta política: emmanuel_canto@aol.com.

Equipment Valuator Privacy Policy

This policy explains how Equipment Valuator, developed by Jonnathan Emmanuel Uicab Canto, processes information when users access its features.

1. Information provided by the user

The application may process technical and economic information entered by the user, such as make, model, year, costs, ages, useful lives, condition, comparables and variables used in valuation methods.

2. Purpose of processing

Information is used to perform calculations, analyses, regressions, value estimates and reports relating to vehicles, machinery and equipment.

3. Processing and storage

Core processing takes place locally. Information may be stored temporarily within the application, and CSV or PDF files are saved only when the user imports or exports them.

4. Information not requested

  • No account is required for core features.
  • The application does not process payments or request banking information.
  • The developer does not automatically receive appraisals, comparables or generated reports.

5. Import and export

The application may use Android file selection tools to import CSV tables and save reports. Users decide which files to open and where to retain the results.

6. Advertising and third-party services

The distributed version may display advertising through Google AdMob. When enabled, Google and its partners may process device identifiers, technical information, ad interactions and other data required to provide and measure advertising.

7. Professional responsibility

The application is a support tool and does not replace professional judgement, physical inspection, applicable regulations or the signature of an authorised valuer. Users are responsible for reviewing data, assumptions and results.

8. Retention and deletion

Users may delete exported files through the device file manager. Uninstalling the application removes internal application data, except for documents stored in public folders.

9. Security

Reasonable measures are applied to limit access to necessary information. Absolute security cannot be guaranteed in electronic systems.

10. Children and changes

The application is intended for valuation professionals and students and is not specifically designed for children. This policy may be updated when features or integrated services change.

Contact

For questions about this policy: emmanuel_canto@aol.com.
